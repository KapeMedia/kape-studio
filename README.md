# KAPE Studio

Aplicația internă a KAPE Media pentru bannere statice on-brand. Specificația: `SPEC.md`. Progres: `PROGRESS.md`.

## Pornire locală

```
pnpm install
pnpm dev
```

Deschide http://localhost:3000. Fără `.env`, aplicația folosește PGlite local (`.data/pglite`), storage local (`.data/uploads`), provideri AI mock și login automat.
